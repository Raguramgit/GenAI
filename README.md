🚀 GenAI is my personal learning and experimentation hub for Generative AI, LangChain, Streamlit, RAG, and Automation.
This repo contains projects, challenge scripts, and demos exploring how AI can be applied in real-world use cases.

📂 Repository Structure

The repo is organized into multiple folders for different learning tracks and experiments:

Langchain/ → Experiments with LangChain modules (LLMChain, PromptTemplate, ChatOpenAI) and custom AI workflows.

Prompt/ → Daily GenAI practice prompts (e.g., Day_13 Challenge).

Python_Chellange/ → My solutions to the 15 Days Python Challenge (learning & consistency journey).

RAG/ → Retrieval-Augmented Generation projects (search + LLM integration).

RPA/ → Robotic Process Automation experiments with GenAI integration.

Sample/ → Miscellaneous sample scripts and prototypes.

Testcases/ → Test scripts for validating GenAI workflows and code.

flask/ → Flask-based AI web applications and quick backend experiments.

streamlit/ → Streamlit apps including:

🏥 Hospital Appointment Scheduler with LangChain (AI-powered descriptions, summaries & cancellations).

Other UI experiments integrating LLMs into real-world workflows.

⚙️ Setup & Installation

Clone the repo

git clone https://github.com/Raguramgit/GenAI.git
cd GenAI


Create a virtual environment

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

Run a Streamlit app (example: Hospital Scheduler)

streamlit run streamlit/Appoinment.py
